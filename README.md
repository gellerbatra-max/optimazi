# Optimazi — website

Marketing / product site for **Optimazi**, the AI-powered fabric-cost optimizer by **Gelian (Pvt) Ltd**.

Optimazi attacks the biggest bottleneck in garment production — marker making and nesting — lifting fabric efficiency from a typical ~70–80% to **85–90%**. Two engines: **Marka** (AI marker maker) and **Ultranest** (AI nesting, roll-matching, PLM/BOM write-back).

## Status — look & feel prototype

The site is being built to a landonorris.com-grade, scroll-driven standard. This repo currently holds the **design prototype** and image assets, ahead of the production build (planned as Next.js + React Three Fiber).

- [`optimazi-look-and-feel.html`](optimazi-look-and-feel.html) — self-contained prototype. Open it directly in a browser. Demonstrates the direction: an animated **topographic-contour background**, a full-screen menu, weighted smooth scroll, a horizontal case-study track, parallax, and the "Blueprint Nocturne" identity.
  - **Palette:** deep indigo-ink ground, warm chalk panels, electric persimmon `#FF5D2E`, blueprint blue `#8FBEDD`.
  - **Type:** Bricolage Grotesque (display), Hanken Grotesk (body), Spline Sans Mono (data).
- Image assets (`*.png`, `*.jpg`) — AI-generated reference imagery (factory floors, CAD/nesting workstations, fabric) for section media. Placeholder/atmosphere; real product screenshots to replace the engine sections.
